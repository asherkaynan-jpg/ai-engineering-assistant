# AI Engineering Assistant

## Project Overview

This project is a beginner AI and Python portfolio project designed to help engineering students organize formulas, solve basic statics/vector problems, and explain technical reasoning step by step.

As a first-year aerospace engineering student, I am using this project to build practical AI, Python, and engineering-analysis skills while developing tools that connect directly to my coursework and career goals.

## Why I Built This

Many first-year engineering students struggle not because they cannot do the math, but because they have trouble organizing the problem-solving process. In courses like Statics, students need to identify forces, draw free-body diagrams, break vectors into components, and check whether their answers make physical sense.

This project is meant to become a simple technical assistant that supports that workflow.

## Current Goals

- Build Python tools for vector addition and force component analysis.
- Create example engineering problems with step-by-step explanations.
- Learn how AI can support engineering education and technical reasoning.
